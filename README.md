Customer & Inventory Management System

Project Overview

This project is a relational database and business intelligence solution designed to manage customers, products, inventory, orders, and payments.

It combines MySQL for database management and Power BI for data analysis and visualization.

Technologies Used

- MySQL 8.0
- MySQL Workbench
- Microsoft Power BI
- SQL
- GitHub

Database Features

- Customer records management
- Product and inventory tracking
- Order management
- Payment tracking
- Low-stock identification
- Sales analysis

Power BI Dashboard

The interactive dashboard provides:

- Total inventory value
- Total units available
- Total sales
- Units sold
- Products needing restock
- Sales by product
- Stock levels by product
- Customer sales and payment status

Database Structure

The database contains five relational tables:

1. Customers
2. Products
3. Orders
4. Order Details
5. Payments

Key Skills Demonstrated

- Relational database design
- SQL queries and joins
- Data analysis
- Data modelling
- Power BI dashboard development
- Business intelligence and reporting

Project Files

This repository includes the Power BI dashboard, a PDF dashboard report, and SQL database export files.
